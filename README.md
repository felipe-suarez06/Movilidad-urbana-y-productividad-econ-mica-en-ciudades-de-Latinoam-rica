
**Título:**  Movilidad urbana y productividad económica en ciudades de Latinoamérica

**¿La congestión vial está relacionada con el desempeño económico de las ciudades?** En este proyecto exploré esa pregunta al combinar indicadores de movilidad urbana con datos económicos y demográficos de ciudades latinoamericanas.

- **Problema:** La congestión afecta los traslados cotidianos y puede influir en la actividad económica y el bienestar de la población. El desafío fue integrar fuentes distintas para comparar el tráfico con indicadores como el PIB per cápita, el desempleo y la población, y evaluar si aparecían patrones relevantes entre las ciudades.
- **Qué hice:** Usé Python y Pandas para preparar y cruzar datos de TomTom Traffic Index con indicadores de OECD Cities. Después analicé las variables y exploré sus relaciones con herramientas de visualización, como seaborn y Matplotlib.
- **Resultado o aprendizaje:**
    - La ciudad con el mayor tiempo promedio de tráfico es: mexico-city
        - No se aprecia que aya una relación directa clara, algunas ciudades con alto PIB: pueden tener más tráfico(como mexico-city) lo que equivaldria más actividad económica o menos tráfico (tal caso el de montevideo) que puede indicar mejor infraestructura Esto sugiere que:
        - El tráfico no depende solo del PIB, puede ser influenciado por otros factores (urbanismo, transporte público, población)
